LinkedIn
========

Aktuální stav LinkedIn stránek spravovaných českou Python komunitou.

Přístup se nesdílí heslem. Kterýkoliv Super admin vás může přidat
v *Settings → Manage admins → Add admin*, a nemusíte být ani
v kontaktech 1. stupně. Pokud chcete přístup, napište některému z adminů.
Content admin může jen přidávat obsah, správce přidávat nemůže.
